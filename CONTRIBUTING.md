## Resumo

1. Faça um fork do repositório e crie sua branch a partir de `main`.
2. Siga o estilo de código existente (Spring Boot, Lombok, MapStruct).
3. Adicione testes para novas funcionalidades.
4. Atualize a documentação correspondente.
5. Abra um Pull Request com título e descrição claros.

Veja o guia completo no seu idioma acima.
